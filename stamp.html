Выберите инструмент, затем проведите по правому изображению (результату).
Загрузите файл
Можно перетащить файл прямо на рабочее поле. Из Word-файла (.doc, .docx, .odt, .rtf) берётся картинка с оттиском; если картинок несколько — выберите нужную кнопками внизу.
⚙️ Тонкая настройка
Поиск оттиска
Отключите первый и третий пункты, если оттиск не круглый. Выравнивание перекошенного оттиска по умолчанию выключено: включите его, если оттиск сфотографирован под углом, или нажмите «Сделать оттиск круглым» на верхней панели.
Фон и чёткость
Больше порог — меньше мусора, но бледные линии могут пропасть. Бледные цветные линии помогает сохранить «чувствительность к цвету».

🎨 Улучшение изображения
Для фото и сканов со слабым разрешением: настройте — оттиск пересчитается сразу. «Авто» подставит умеренные значения.
Резкость подчёркивает мелкие детали, «резкость краёв» усиливает только границы линий и букв. Шумоподавление уберёт зернистость слабых фото.

Перетащите файл сюда

Фото, скан, PDF или файл Word. Либо нажмите на это поле.

•Загрузите файл — оттиск очистится сам.
•При необходимости уберите лишнее ластиком и «Уточнением края».
•Скачайте PNG или добавьте печать в память для «Автозаполнения».
Рабочая зона на листе Тяните рамку мышью, за углы меняйте размер, колесом мыши — масштаб рамки. Программа ищет печать только внутри рамки.
